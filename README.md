##Simple Calculator

A console-based calculator application developed using Python and Object Oriented Programming Language(OOPS)

##Features
- Addition
- Subtraction
- Multiplication
- Division
- Show calculation history
- Clear calculation history
- Input validation using exception handling

##Technologies used 
- python 3
- Object-oreinted Programming OOPS
- File Handling
- Exception Handling

##How to Run

1. Clone the Repository
2. Open the project folder
3. Run: 
```bash
python console_calculator.py
